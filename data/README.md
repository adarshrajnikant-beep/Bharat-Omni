Bharat-Omni Data
Ye folder Bharat-Omni ke training data ke liye hai.

Structure
sample.json - 8 samples ka demo dataset (All-to-All)
images/ - Fasal, kagaj, etc ki photos daalo
audios/ - Bhashaon ki voice notes daalo
videos/ - Khet, machine ke videos daalo
Format
Har sample me messages array hai:

user: <image> <audio> <video> tag ke saath sawal
assistant: Jawab
Naya data add karna hai to sample.json me same format me add karo.
